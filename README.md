An enterprise-grade, microservices-based system built with Spring Boot, PostgreSQL, Docker, and Kubernetes.

## System Components
- *API Gateway*: Routing and API entry point
- *Auth Service*: User authentication and JWT management
- *Asset Service*: ICT hardware/software lifecycle tracking
- *Maintenance Service*: Repair logs, costs, and service schedules

## Tech Stack
- *Java 21 / Spring Boot*
- *Database*: PostgreSQL (Database-per-service pattern)
- *Containerization*: Docker & Docker Compose
- *Orchestration*: Kubernetes (Minikube)
- *Version Control*: Git & GitHub
